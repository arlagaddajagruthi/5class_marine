## Proposed Changes

### Phase 1: Random Forest Feature Extraction & Training
The current codebase only extracts raw spectral signatures for tabular analysis. 
- **[NEW] `utils/rf_pipeline.py`**: I will write a completely new script that:
  1. Computes **Spectral Indices** (NDVI, FAI, NDWI, etc.) pixel-by-pixel.
  2. Computes **GLCM Textural Features** (Contrast, Dissimilarity, Homogeneity, Energy, Correlation) using scikit-image on a sliding window.
  3. Flattens the valid pixels (discarding background) and trains a `RandomForestClassifier`.
  4. Evaluates the model and prints metrics (Precision, Recall, F1, IoU).

### Phase 2: Generalizing the Deep Learning Pipeline
Currently, the `marinext/train.py` script hardcodes the `MariNext` wrapper and its specific config file.
- **[MODIFY] `marinext/train.py` & `marinext/marinext_wrapper.py`**: Refactor these to accept a model `--config` argument so we can switch between MariNeXt, U-Net, and SegNeXt dynamically without changing the training loop.
- **[NEW] Configuration Files**:
  - `marinext/configs/unet_5class.py`: Define a standard U-Net architecture using the `mmsegmentation` UNet backbone and an FCN decode head.
  - `marinext/configs/segnext_5class.py`: Define the baseline SegNeXt architecture.
  - `marinext/configs/marinext_5class.py`: Modify the existing MariNeXt config to use `num_classes=5`.

### Phase 3: Orchestration Scripts
- **[NEW] `run_all_experiments.ps1`**: A PowerShell script that automates the training and evaluation of all models across both datasets, saving logs and checkpoints to organized directories (e.g., `logs/MARIDA_5Class_UNet/`).

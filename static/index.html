How it works

  1. Read the 11 Sentinel-2 bands (B1–B8, B8A, B11, B12) as surface reflectance. The infrared bands matter most: clear water absorbs near- and short-wave infrared, while anything floating reflects it.
  2. Compute features for every pixel: the 11 bands, NDWI, four band ratios (red/green, NIR/red, NIR/green, SWIR1/NIR), and, for stage-8 models, six GLCM texture features from a 13×13 window.
  3. Classify each pixel with a Random Forest (100 trees, log class weights) into Water, Marine Debris, Algae/Sargassum or Other, with a probability for each class.
  4. Group neighbouring pixels of the same class into patches and report each patch's size, area, confidence and location.

Limitations

  • Sentinel-2 only. Ordinary photos (JPG/PNG, Google Maps) have no infrared bands, so they cannot be analysed.
  • Different processing. MARIDA and MADOS images were atmospherically corrected in a particular way. Standard Sentinel-2 L1C/L2A downloads differ, so expect lower accuracy on them than the test scores above.
  • Ocean only. The model never saw land or clouds. The cloud/land guard masks the obvious cases, but coastlines can still be mislabelled.
  • 10 m pixels. Only aggregated debris (patches and windrows tens of metres long) is visible, not single items.
  • Pixel-based. Each pixel is classified from its own spectrum plus local texture. The U-Net + RF ensemble in the repository scores higher but needs the trained U-Net weights.

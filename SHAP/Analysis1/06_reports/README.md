# SHAP figure index

Generated by `scripts/feature_analysis/shap_figures.py` from the stage-8 models (22 features, log weights) explained in `per_class_features.py`. The write-up is `docs/feature_analysis.md`.

Classes: 1 Water, 2 Marine Debris, 3 Algae/Sargassum, 4 Other. Models: RF, XGBoost, LightGBM, AdaBoost, linear SVM. SHAP output units differ per model (probability, log-odds, decision score), so models are compared through shares (% of mean |SHAP|).
